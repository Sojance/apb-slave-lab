# Лабораторная работа: Разработка APB Slave

Студент: Степанов Иван Андреевич
Группа: М3О-409Б-23
Номер в списке: 7

Описание проекта
Репозиторий содержит реализацию периферийного устройства APB (Advanced Peripheral Bus) Slave на языке SystemVerilog, а также тестбенч (testbench) для проверки его работоспособности.

Функциональность
1. Базовый APB Slave: Поддерживает операции чтения и записи.
2. Логика регистра 0x0: При записи `0` в младший бит регистр сохраняет `0xAAAAAAAA`, при записи `1` — `0x55555555`.
3. Студенческие данные:
  `0x0` — Номер в группе (7).
  `0x4` — Дата (27.10.2026).
  `0x8` — Фамилия ("Step" в ASCII).
  `0xC` — Имя ("Ivan" в ASCII).
